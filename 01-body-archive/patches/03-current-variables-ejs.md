# 卡内补丁 #3：`[variables]当前变量` EJS 追加段

> **⚠️ P0 关键 — 不加此补丁 AI 看不到动态肉体档案**

## 位置

角色卡世界书条目 `[variables]当前变量`，在构建 `current.角色` 对象的代码块内。

> 名称对照：V3.6.11 起变量根节点 `主角` → `角色`。迁移 V3.5.x 及更早的卡时，把 `current.角色` / `data.角色` 读作 `current.主角` / `data.主角`。

## 原因

该 EJS 的 `current.角色` 是**逐字段手写**的（`{ 种族, 身份, 职业, HP, THP, EP }`，非战斗时另挂 `空间币` / `权限凭证`），
不是对 `data.角色` 整体展开。不加此补丁，`动态肉体档案` 不会出现在 `<status_current_variables>` 里，AI 能写但**读不到**当前值。

## 锚点

找到 `current.角色` 的对象字面量收尾处（`EP: data.角色.EP` 行 + 紧接的 `};`），在 `EP` 行之后追加。

V3.6.11 原文（注意 `};` 之后还有一段非战斗才追加 `空间币` / `权限凭证` 的代码，**不要**把补丁插到那里面去）：

```javascript
current.角色 = {
  种族: data.角色.种族,
  身份: data.角色.身份,
  职业: data.角色.职业,
  HP: data.角色.HP,
  THP: data.角色.THP || 0,
  EP: data.角色.EP
};
```

## 补丁原文

把 `  EP: data.角色.EP\n};` 替换为：

```javascript
  EP: data.角色.EP,
  动态肉体档案: data.角色.动态肉体档案
};
```

完整效果（`current.角色` 块尾部）：

```javascript
current.角色 = {
  种族: data.角色.种族,
  身份: data.角色.身份,
  职业: data.角色.职业,
  HP: data.角色.HP,
  THP: data.角色.THP || 0,
  EP: data.角色.EP,
  动态肉体档案: data.角色.动态肉体档案
};
```

## 注意

- 空 record 序列化为 `{}` 几乎不占 token，直接带上即可；本补丁沿用 V3.5.6 的做法**无条件下发**（战斗/非战斗都带），
  因为战斗中的 NSFW 场景同样需要读取档案。若要省 token，也可改成与 `空间币` 一样只在 `if (!isCombat)` 分支里挂。
- 该 EJS 顶部的守卫 `if (!data || !data.角色) { … 数据为空 … }` 在 V3.6.11 已同步改名，无需改动。
- 条目末尾的 `_stripForbidden()` 只递归剔除 `真属性`（以及实体顶层的废弃 `强化`），不会误删 `动态肉体档案`。
